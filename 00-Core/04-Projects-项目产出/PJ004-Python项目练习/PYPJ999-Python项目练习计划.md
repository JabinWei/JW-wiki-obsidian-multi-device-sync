# PJ004-Python项目练习 项目文档

## 🎯 项目目标

PL001 语言笔记已覆盖 **PY001–PY031**（基础语法 → 数据结构 → 函数式 → 面向对象 → 数据库 → 并发 → 工程化）。已经完成了 Python 基础学习，本计划提供一系列项目练习，通过**做项目温故知新**，每个项目都要求写单元测试，巩固知识点，养成测试驱动开发的好习惯。

## 💡 练习方式

已经完成了基础学习，可以**按兴趣任意选择项目**练习，不需要按顺序：

1. 选一个感兴趣的项目，看需求说明
2. 实现功能，同时写单元测试测试你的代码
3. 运行测试，直到所有测试都通过
4. 完成后写笔记总结，记录你遇到的问题和学到的东西
5. 如果想巩固工程化，可以选一个已完成的项目做工程化重构

每个项目都是独立的，想做哪个做哪个，随时可以换，保持节奏最重要。

---

## 💡 详细练习方式（参考 exercism 理念）

1. **每个项目都先看需求，然后看单元测试**，理解每个函数应该做什么
2. **逐步实现函数**，写完一个就运行一次测试，看测试是否通过
3. **全部测试通过后**，再实现 CLI 交互部分（如果有）
4. **做完写笔记总结**，记录你遇到的问题和学到的知识点，总结在对应的 `PYPJxxx-项目名.md` 中
5. **不想做就跳过**：如果对某个项目没兴趣，直接换下一个，保持节奏最重要
6. **做完就放GitHub**：每个项目一个仓库，或者放到同一个 practice 仓库，积累作品集

## 💡 为什么要这样练习？

- 从一开始就**养成写测试的习惯**，每个函数都有测试，你会立刻知道写对了还是错了
- 小步快跑，写完一个测试通过再写下一个，学习曲线更平滑
- 测试本身帮助你理解需求，每个测试用例就是一个具体场景
- 锻炼你阅读测试、理解别人代码的能力，这和工作中开发维护项目是一样的

## 📁 代码文件命名规范

根据 PEP 8 约定：
- Python 代码文件名使用 **下划线分隔（snake_case）**：`guess_number.py` ✅，不是 `guessNumber.py` ❌
- 类名使用大驼峰（PascalCase）：`class GuessNumberGame:` ✅
- 函数名/变量名使用下划线分隔：`def generate_number():` ✅

## 🔧 环境准备

只需要安装 `pytest` 就可以运行所有测试：
```bash
pip install pytest
```

运行测试：
```bash
cd 项目目录
pytest test_xxx.py -v
```
