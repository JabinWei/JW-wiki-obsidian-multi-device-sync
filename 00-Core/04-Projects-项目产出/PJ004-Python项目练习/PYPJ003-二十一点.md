## 🎯 项目
二十一点（21点 / Black Jack）

## 📜 游戏规则
二十一点是一个经典扑克牌游戏，目标是让手中牌的总点数**不超过 21 点**，并且比庄家的点数更大。

- **牌的点数**：
  - 牌面数字 2~10 → 按牌面数字算点
  - J/Q/K → 都是 10 点
  - A（Ace）→ 既可以算 1 点，也可以算 11 点，根据哪种情况最优来决定

- **核心策略规则**（本题要实现的判断逻辑）：
  1. 计算总点数时，如果有 A，选择不超过 21 的最大总点数；如果所有选择都超过 21，选择最小总点数
  2. 只有玩家刚好两张牌且两张牌**点数相同**才可以分牌（10 和 K 点数都是 10，也可以分）
  3. 判断是否应该停牌（停止叫牌）的基本策略：
     - 玩家总点数 ≤ 11 → **必须继续叫牌，不停牌**
     - 玩家总点数 ≥ 17 → **必须停牌**
     - 玩家总点数在 12~16 之间 → 如果庄家明牌 ≥ 7，继续叫牌；否则停牌

## 📝 功能需求（根据 Exercism 题目要求）
- [ ] `card_value(card) -> int`：返回单张牌的固定点数，A 返回 1（动态计算在 `hand_total` 处理）
- [ ] `hand_total(hand) -> int`：计算一手牌的最优总点数，处理 A 的两种选择
- [ ] `can_split_pair(hand) -> bool`：判断当前两张牌是否可以分牌
- [ ] `should_stand(dealer_card, player_hand) -> bool`：根据规则判断玩家是否应该停牌
