## 🎯 项目目标

PL001 语言笔记已覆盖 **PY001–PY031**（基础语法 → 数据结构 → 函数式 → 面向对象 → 数据库 → 并发 → 工程化）。本计划用「分级实战项目」把散落在各篇笔记里的知识点串起来，边做边巩固，从「会语法」过渡到「能独立写小工具」。

## 📝 推荐路线

1. **成绩管理器（PYPJ003）** → 数据结构 + 文件操作练习最全面，先做
2. **Todo-CLI（PYPJ005）** → 第一个「类 + 持久化」的完整小工具，体会封装价值
3. **文件整理工具（PYPJ007）** → 直接服务本仓库（批量整理图片名/资产），个人实用
4. **单词本升级（PYPJ006）** → 顺带练高阶函数 / partial / 装饰器，与英语学习结合
5. **图书库存（PYPJ008）** → 落地数据库 CRUD + 日志
6. **多线程下载器（PYPJ009）→ 进程/异步（PYPJ010）** → 并发用法巩固（原理等 OS 基础补完后再深挖）
7. **工程化收尾（PYPJ011）** → 用类型注解 + 测试 + 日志把任意项目打磨一遍

> 阶段四不是独立大项目，而是「给老项目打补丁」——挑一个自己最满意的项目，补上注解、测试、日志和模块拆分，即算完成。
