## 🎯 项目目标

PL001 语言笔记已覆盖 **PY001–PY031**（基础语法 → 数据结构 → 函数式 → 面向对象 → 数据库 → 并发 → 工程化）。本计划用「分级实战项目」把散落在各篇笔记里的知识点串起来，边做边巩固，从「会语法」过渡到「能独立写小工具」。

> 项目默认只用 **Python 标准库**；阶段三起才引入 MySQL / 并发，均不依赖第三方库（requests、pandas 等按需再装）。

## 📝 推荐实践路线

### 👉 如果你是刚开始做项目，按这个顺序来：

1. **猜数字（PYPJ002）** → 热身，感受完整程序的输入输出流程
2. **井字棋（PYPJ003）** → 练二维数据结构和胜负判断逻辑
3. **学生成绩管理器（PYPJ004）** → 练数据结构+文件操作，把基础串起来
4. **Todo-CLI（PYPJ006）** → 第一个面向对象完整小工具
5. **文件整理工具（PYPJ009）** → 做个能用的工具，直接服务你的Obsidian仓库
6. **贪吃蛇（PYPJ010）** → 做个小游戏放松一下，同时练OOP和事件处理
7. 等学完数据库 → SQLite日记本 → 图书管理系统
8. 等学完并发 → 多线程下载器 → 异步任务处理
9. 最后挑一个最喜欢的项目做工程化升级

## 💡 项目选择原则

1. **不想做就跳过**：如果对某个项目没兴趣，直接换下一个，保持节奏最重要
2. **先能跑，再优化**：不要一开始就追求「优雅代码」，先写出能工作的版本，再重构
3. **做完就放GitHub**：每个项目一个仓库，或者放到同一个practice仓库，积累作品集
4. **记笔记**：每个项目做完写一篇笔记，总结遇到的坑和学到的东西（对应这里的PYPJ编号）
