## 🎯 项目
井字棋（Tic-Tac-Toe）

## 📝 功能需求
- [ ] 双人对战（两个人在同一台电脑轮流下）
- [ ] 棋盘用 3x3 二维列表表示，每次下完重新打印棋盘
- [ ] 落子前检查：坐标是否合法、是否已经有棋子
- [ ] 每次落子后判断：是否分出胜负/平局
- [ ] 胜负判断：横、竖、对角线三个相同棋子即为胜利
- [ ] 棋盘满了没分出胜负就是平局
- [ ] 结束后询问是否再来一局

## 💡 设计思路

### 棋盘表示
用一个长度为 9 的一维列表，或者 3x3 二维列表都可以，二维更直观：
```python
# 初始空棋盘
board = [
    [' ', ' ', ' '],
    [' ', ' ', ' '],
    [' ', ' ', ' ']
]
```

### 整体流程
```
1. 欢迎信息 → 新建棋盘 → 当前玩家 = 'X'
2. 打印棋盘
3. 提示当前玩家输入坐标（比如输入 1 1 表示第一行第一列）
4. 验证输入：
   - 是否是两个数字 → 不合法重输
   - 坐标是否在 1-3 范围内 → 不合法重输
   - 位置是否已经有棋子 → 有棋子重输
5. 落子 → 更新棋盘
6. 判断胜负：
   - 胜利 → 打印棋盘 → 宣布胜利 → 询问是否再来
   - 平局 → 宣布平局 → 询问是否再来
   - 继续 → 交换玩家 → 回到第2步
```

### 判断胜负方法
检查所有可能赢的线（8条：3横 + 3竖 + 2对角）：
- 三条横线：每一行三个都一样（不是空格）就是赢
- 三条竖线：每一列三个都一样（不是空格）就是赢
- 两条对角线：对角线三个都一样（不是空格）就是赢
- 如果所有格子都满了还没人赢 → 平局

### 需要用到知识点
- 二维列表操作
- 嵌套循环打印棋盘
- `split()` 分割用户输入
- `try-except` 处理输入不合法
- 玩家交换：`current_player = 'O' if current_player == 'X' else 'X'`
- 多局循环

## 🛠 逐步实现计划

3. **第三步**：落子逻辑，交换玩家
4. **第四步**：最重要的一步 → 实现胜负判断

- [ ] 平局判断漏了 → 要检查棋盘是否已经填满
