### 并发学习阶段（Python 线程/进程）

**是什么**：用户学 Python 线程/进程（[[PY026-线程]]/[[PY027-进程]]）时，反复卡在底层原理（为什么 Lock 保证线程安全、进程内存隔离、Queue 传副本的意义）。根因是缺少操作系统并发基础（进程/线程/内存模型/并发并行/同步原语）。

**为什么**：直接学 threading/multiprocessing 封装，没有 OS 底层概念垫着，导致「为什么」类问题反复卡住，讲多轮仍难通透。

**如何应用**：用户已决定先只了解 Python 用法（创建线程/进程、Lock、Queue、Pool 的 API 和场景），等补完「操作系统-并发基础」后再回来深入原理。遇到底层原理问题，默认停在用法层面，不要反复展开；用户追问原理时，先引导补 OS 基础而非继续堆 Python 层面说明。
