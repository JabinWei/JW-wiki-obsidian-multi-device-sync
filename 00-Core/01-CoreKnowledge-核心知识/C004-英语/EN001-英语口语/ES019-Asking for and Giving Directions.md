## 🎯 学习目标

- 用英语礼貌地问路："Excuse me, do you know where... is?"
- 用英语清晰地指路，使用顺序词 first / then / next / finally
- 掌握交通方式表达：take a bus / take the subway / take a taxi / walk
- 区分 "by bus"（方式状语）和 "take a bus"（动词短语）
- 用地铁换乘表达：take line 2, get off at..., transfer at...
- 用 "I've got this" / "Don't worry" 表示自信带路

## 📚 核心内容

### 一、问路的礼貌句型

| 句型 | 中文 | 备注 |
|------|------|------|
| Excuse me, do you know where the bank is? | 打扰一下，你知道银行在哪吗？ | 最礼貌的问法 |
| Do you know where... is? | 你知道…在哪吗？ | 通用问法 |
| How do I get to...? | 我怎么去…？ | 直接问路线 |
| How can I get there? | 我怎么去那？ | 同上 |
| Excuse me, is there a... near here? | 请问附近有…吗？ | 找附近的东西 |

### 二、指路的顺序词

用顺序词让路线清晰易跟随：

```
First,  you need to walk to the bus station.
Next,   take the number 38 bus to Green Park station.
Then,   take the subway to...
Finally, walk about 5 minutes to the bank.
```

| 顺序词 | 中文 |
|--------|------|
| First | 首先 |
| Next / Then | 然后 / 接着 |
| After that | 在那之后 |
| Finally | 最后 |

### 三、交通方式的表达

这是本课核心语法的重点！

#### ✅ 正确表达（动词短语）

```
take a bus          → 坐公交
take the subway     → 坐地铁
take a taxi         → 坐出租车
walk                → 步行
```

#### ❌ 常见错误

```
❌ I can go there by bus.    → by bus 是方式状语，不能这样单独作谓语
✅ I can take a bus there.   → 正确
✅ I can go there by bus.    → 但这个句子本身也可以（by bus 修饰 go）

❌ I by bus to work.          → 完全错误
✅ I take a bus to work.      → 正确
```

> 老师说：很多中国学生会直接用 "by bus" 当动词用，这是错误的。"by bus" 只能做状语修饰动词。

#### take + 交通工具的细节

```
take a bus           → 坐公交车（可数）
take the subway      → 坐地铁（用 the，地铁是一个系统）
take a taxi          → 坐出租车（可数）
take the train       → 坐火车（用 the）
on foot / walk       → 步行
```

### 四、地铁相关表达

```
take the subway                 → 坐地铁
take line 2                     → 坐2号线
get off at Green Street station → 在Green Street站下车
transfer at...                  → 在…换乘
change to line 4 at...          → 在…换乘4号线
How many stops?                 → 多少站？
About 3 stops.                  → 大约3站。
```

**关于 red line 的说法**：
- 英美通常用数字/名字："take line 2"、"take the Piccadilly line"
- "red line" 在某些城市也可以，但通常是游客说法

### 五、地图与位置表达

```
check the map                  → 查一下地图
Let me check the map.          → 让我看下地图。
It's near the park.            → 它在公园附近。
It's on Hill Street.           → 它在Hill Street上。
The bank is just around there. → 银行就在那附近。
We can see the bank nearby.    → 我们可以在附近看到银行。
```

### 六、自信带路的表达

```
I've got this.              → 交给我吧。/ 我搞得定。
Don't worry, I know the way. → 别担心，我认识路。
Follow me.                   → 跟我来。
It's not far.               → 不远。
About 10 minutes on foot.   → 走路大约10分钟。
```

> "I've got this" = I can handle it. 是非常口语化、表示自信的表达。

### 七、完整问路对话

**场景一：问路**

```
A: Excuse me, do you know where the museum is?
B: Yes, it's on Hill Street.

A: How do I get there?
B: First, you need to take the subway, line 2.
   Get off at Green Street station.
   Then, walk about 5 minutes.
   You'll see the museum on your left.

A: Thank you so much!
B: You're welcome.
```

**场景二：两人一起找路**

```
A: I think we might be lost. Do you know how to get to the bank?
B: Let me check the map.

A: Do you have a good sense of direction?
B: Don't worry, I've got this.

B: First, we need to find a bus station.
   We can take the number 38 bus to Green Park.
   Then, we need to take the subway there. Take line 2.
   Get off at Leicester Square station.
   Finally, we need to walk about 10 minutes.
   We should see the bank nearby.

A: Sounds good. Let's go!
```

### 八、问路的多种交通组合

```
First, walk to the bus station.
Then, take the bus to the subway station.
Next, take the subway to the museum.
Finally, walk to the entrance.
```

或更简单的：

```
You can take a taxi to the museum.   → 坐出租车
You can walk to the station.         → 走路去车站
You can get to school by bus.        → 坐公交去学校
```

### 九、核心语法纠正

```
❌ I go there by subway.       → 语法上没错但日常口语更常说：
✅ I take the subway there.

❌ Take a subway.              → subway 用 the，因为它是系统
✅ Take the subway.

❌ Get off the subway.         → 需要 station
✅ Get off at the next station.

❌ We need walk 5 minutes.     → 缺少 to
✅ We need to walk 5 minutes.
```
