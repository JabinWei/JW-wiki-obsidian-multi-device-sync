## 🎯 学习目标

- 用英语说出常见运动和活动名称（badminton, surfing, yoga, ice hockey 等）
- 掌握三大运动动词分类：play + 球类、do + 个人运动、go + -ing 活动
- 用 "I love/like/enjoy doing..." 表达对活动的偏好
- 用 "because it's + 形容词" 给出喜欢/不喜欢的理由
- 用 "Sorry, do you mean...?" 礼貌地确认对方的意思
- 用 "I'd like to try..." 表达想尝试某活动
- 区分 "try to do" 和 "try doing"

### 二、运动动词三大分类

这是本课最核心的语法规则：

| 动词 | 用于 | 规则 | 例句 |
|------|------|------|------|
| **play** | 球类运动/竞技游戏 | play + 运动名 | play badminton, play baseball |
| **do** | 个人/武术类 | do + 活动名 | do yoga, do karate |
| **go** | -ing 结尾的活动 | go + 动词-ing | go swimming, go surfing |

```
✅ play basketball    ✅ play table tennis    ✅ play ice hockey
✅ do yoga             ✅ do karate             ✅ do exercise
✅ go swimming         ✅ go surfing            ✅ go ice skating
```

> **例外**：`do sports` 和 `play sports` 都可以，两者都常见。

### 三、表达偏好的句型

#### 喜欢

| 句型 | 语气强度 | 例句 |
|------|----------|------|
| I love playing... | ⭐⭐⭐ 热爱 | I love playing badminton. |
| I really enjoy doing... | ⭐⭐⭐ 非常享受 | I really enjoy doing yoga. |
| I like going... | ⭐⭐ 喜欢 | I like going swimming. |
| I'd like to try... | ⭐ 想尝试 | I'd like to try surfing. |

#### 不喜欢

| 句型 | 例句 |
|------|------|
| I don't like playing... | I don't like playing ice hockey. |
| I really don't like going... | I really don't like going swimming. |
| I hate doing... | I hate staying at home all day. |

### 四、给出理由（Reasons）

这是本课的进阶重点：不只说喜欢/不喜欢，还要说**为什么**。

#### 用于描述活动的形容词

| 形容词 | 中文 | 例句 |
|--------|------|------|
| exciting | 令人兴奋的 | Playing soccer is so exciting. |
| relaxing | 令人放松的 | Doing yoga is relaxing. |
| boring | 无聊的 | Playing ice hockey is boring. |
| difficult | 困难的 | Playing baseball is difficult. |
| fun | 有趣的 | Table tennis is fun. |
| healthy | 健康的 | Swimming is healthy. |
| dangerous | 危险的 | Surfing is dangerous. |

#### 完整句型：偏好 + 理由

```
I love playing soccer because it's so exciting.
→ 我热爱踢足球，因为它很令人兴奋。

I enjoy doing yoga because it's relaxing.
→ 我喜欢做瑜伽，因为它能让人放松。

I don't like playing ice hockey because it's boring.
→ 我不喜欢打冰球，因为它很无聊。

I'd like to try surfing, but I'm not sure if it's dangerous.
→ 我想尝试冲浪，但我不确定它是否危险。
```

#### 更好的理由方式

不只用 `because` + 形容词，可以扩展：

```
✅ 简单理由: I like yoga because it's relaxing.
✅ 更好: I like doing yoga because it helps me relax after work.
✅ 更好: Yoga is relaxing. It's a really good exercise.
✅ 更好: I love doing yoga. It's a lot of fun and it keeps me healthy.
```

### 五、"Sorry, do you mean...?" — 礼貌确认

当你不确定对方的意思时，这是非常有用的句式：

```
A: I love table tennis.
B: Sorry, do you mean watching or playing table tennis?
A: Playing! I play every weekend.

A: I enjoy badminton.
B: Sorry, do you mean you enjoy watching it or playing it?
A: I like watching it, but I rarely play it.
```

> **老师说**："This is a great way to do paraphrasing, especially in interviews. You can buy yourself some time, and you can check if you understand correctly."

**其他确认句式：**

```
What do you mean?               → 你是什么意思？（较直接）
Sorry, do you mean...?          → 抱歉，你的意思是…？（更礼貌）
Do you mean watching or playing? → 你是指观看还是参与？
```

### 六、"try to do" vs "try doing"

```
❌ I want to try to go surfing.     → 不地道
✅ I'd like to try surfing.         → 自然地道的表达

try + 动词-ing  → 尝试做某事（体验一下）
try to + 动词   → 努力做某事（克服困难）
```

```
I'd like to try surfing.    → 我想试试冲浪。（体验）
I tried to finish the work. → 我努力完成工作。（克服困难）
```

### 七、完整对话模板

**Talking About Sports and Activities:**

```
A: Do you like any sports?
B: Yes, I love playing tennis. It's so exciting!

A: Do you do any other sports?
B: I also enjoy badminton.

A: Sorry, do you mean playing badminton or watching it?
B: I like watching it, but I rarely play it. How about you?

A: I don't like playing badminton, but I love going swimming.
   It's relaxing and it's really good exercise.
B: That's true. Swimming is a lot of fun.
```

**谈论想尝试的活动：**

```
A: What activities do you want to try?
B: I'd like to try surfing. It looks so exciting!

A: Are you sure? Surfing can be dangerous.
B: I'm not sure if it's dangerous for me or not, but I still want to try.

A: That's brave! I prefer relaxing activities like doing yoga.
B: Yoga is great too. It's a really good way to relax.
```

### 八、推荐表达积累

```
That's a really good exercise.  → 那是很好的锻炼方式。
It's a lot of fun.              → 这很有趣。
It can really help you relax.   → 它真的能帮你放松。
I'm not sure if...              → 我不确定是否…
I worry if it's dangerous.      → 我担心它是否危险。
```
