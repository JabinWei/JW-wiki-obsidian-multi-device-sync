## 🎯 学习目标

- 用 "Why don't we...?" 提出更有力的活动建议
- 区分四种提议句型的强弱（Why don't we > Let's > How about > What about）
- 用 "You want to...?"（升调）将陈述句变为疑问句
- 掌握 "don't you" 连读为 "don-chu"
- 正确发音 "good"（不重读 d）、"I don't feel like it"（T 不读成 特）
- 用 "I haven't been there" 代替 "I have not gone there"

## 📚 核心内容

### 一、四种提议句型及强弱排序

| 句型 | 强度 | 含义 |
|------|------|------|
| **Why don't we...?** | ⭐⭐⭐ 最强 | 强烈建议/催促 |
| **Let's...** | ⭐⭐ 直接提议 | 一起做吧 |
| **How about...?** | ⭐ 商询建议 | 征求对方意见 |
| **What about...?** | ⭐ 商询建议 | 同上，或提替代方案 |

> **老师说**："Why don't we go to the beach?" 是四种里面语气最强的。其余三种更像是在询问对方的意见。

### 二、周末活动地点词汇

| 地点 | 英文 | 相关活动 |
|------|------|----------|
| 公园 | park | go running, have a picnic |
| 海滩 | beach | swimming, beach volleyball |
| 图书馆 | library | read, study |
| 电影院 | cinema | watch a movie |
| 博物馆 | museum | visit exhibitions |
| 游泳池 | swimming pool | go swimming |
| 咖啡馆 | cafe | drink coffee, chat |

### 三、陈述句变疑问句 — "You want to...?" 模式

直接把陈述句末尾语调上扬，变成问句：

```
You want to go swimming? ↗           → 你想去游泳吗？
You don't want to go to the cinema? ↗ → 你不想去电影院吗？
You don't feel like it? ↗             → 你不想去吗？
```

> 老师说："Statement + question mark with a raising tone" — 日常口语中非常常见。
> 比 "Do you want to...?" 更简洁自然。

**练习：**

```
Why don't you want to go to the museum?
→ You don't want to go to the museum? ↗

Don't you feel like it?
→ You don't feel like it? ↗
```

### 四、"don't you" 连读发音

```
don't you → don-chu  （T + you = "ch" 音）

Don't you want to go?   →  Don-chu wanna go?
Don't you feel like it? →  Don-chu feel like it?
```

> 这是美式英语中非常自然的连读，T + Y 变成 "ch" 音。

### 五、关键发音点

#### "good" — 不要重读 d

```
❌ goo-DUH（d 太用力）
✅ goo(d) — d 极轻，几乎不发音

Good morning. → 不是 Goo-DUH morning
Good idea.    → 不是 Goo-DUH idea
```

> 老师说中文类比：就像松着嘴巴自然放下，不需要用力绷紧。

#### "I don't feel like it" — T 的处理

```
❌ I don't feel like 特（用中文"特"替代 /t/）
✅ I don't feel like i(t) — T 极轻

中国学生常把 T 读成中文的"特"，这是不正确的。
英语的 /t/ 是轻轻带过，不是用力弹舌。
```

#### "want to" → "wanna"

```
want to → wanna （口语连读）

You want to go?    →  You wanna go?
I want to try.     →  I wanna try.
```

### 六、"I haven't been there"

```
❌ I have not gone there.      → 不自然
✅ I haven't been there.       → 我还没去过那里。

I haven't been to that museum yet.
→ 我还没去过那个博物馆。
```

> `have/has been to` 表示"去过"（经历）
> `have/has gone to` 表示"去了"（还在那）

### 七、回应建议的表达

#### 赞同

```
That's a good idea.         → 好主意。
That's a great idea!        → 太好的主意了！
Sounds good!                → 听起来不错！
I think that's a deal!      → 就这么定了！
```

#### 婉拒/不确定

```
I'm not sure.               → 我不确定。
I don't feel like it.       → 我不太想去。
I don't know.               → 我不知道。
You have a point, but...    → 你说的有道理，但…
```

**"You have a point, but..."** — 非常实用的先肯定后婉拒模式：

```
A: Why don't we go to the park? We can do some exercise.
B: You have a point, but I'm not a big fan of doing exercise.
   Any other things we could do?
```

### 八、完整周末计划对话

```
A: Hey, it's Saturday! What do you want to do today?

B: Why don't we go to the park in the morning?
   We can do some exercise there.

A: You have a point, but I'm not a big fan of exercise.
   How about going to the museum instead?

B: The city museum? I haven't been there!

A: Me neither. Let's go there in the morning.

B: Sounds good. And there are some new movies at the cinema.
   How about going to the cinema in the afternoon?

A: That's a great idea! You want to get coffee first?

B: Sure! I'm dying for a cup of coffee. Let's do that.

A: I think that's a deal!
```

### 九、"I'm dying for..." — 极度渴望

```
I'm dying for a cup of coffee.    → 我超想喝杯咖啡。
I'm dying to see that movie.      → 我超想看那部电影。
```

> 比 "I really want" 更夸张、更口语化。
