## 🎯 学习目标

- 用英语描述公寓/房屋的基本信息（几室几厅、面积、租金）
- 掌握租房相关词汇：rent, furnished, spacious, close to, garage 等
- 读懂英文租房广告中的缩写（BDRM, BTH, PCM, PPL）
- 用 "fully furnished" vs "limited furniture" 描述家具配置情况
- 用 "I prefer... because..." 比较并选择公寓
- 读英文数字（四位数价格如 £1,600 = sixteen hundred）

## 📚 核心内容

| house | 独立房屋 | — |

### 三、租房广告缩写速查

| 缩写 | 全称 | 中文 |
|------|------|------|
| BDRM | bedroom | 卧室 |
| BTH | bathroom | 浴室 |
| PCM | per calendar month | 每月（房租支付周期） |
| PPL | people | 人（入住人数） |
| furn. | furnished | 带家具 |
| unfurn. | unfurnished | 不带家具 |
| sq ft | square feet | 平方英尺 |
| util. incl. | utilities included | 含水电费 |

**示例广告：**
```
2 BDRM, 1 BTH apt.
Fully furnished. Close to public transportation.
£1,600 PCM
```

**解读**：
- 两个卧室、一个浴室的公寓
- 家具齐全
- 靠近公共交通
- 每月 1,600 英镑

### 四、租房的四大关注点

#### 1. 租金 (Price/Rent)

```
How much is the rent?              → 租金多少？
It's £1,600 per calendar month.    → 每月1,600英镑。
It's 1,600 pounds a month.         → 同上（更口语）
```

#### 2. 位置 (Location)

```
It's close to a supermarket.           → 靠近超市。
It's near public transportation.       → 靠近公共交通。
It's in a good area / neighborhood.    → 地段好。
It's far from my company.              → 离我公司远。
It's not far away from the subway.     → 离地铁不远。
```

#### 3. 大小 (Size)

```
It's a two-bedroom apartment.      → 两室公寓。
It's spacious.                     → 很宽敞。
How big is it?                     → 有多大？
It's about 80 square meters.       → 大约80平米。
```

#### 4. 家具 (Furniture)

```
It's fully furnished.              → 家具齐全。
It comes furnished.                → 带家具。
It's unfurnished.                  → 不带家具。
It has limited furniture.          → 家具有限（仅有基本家具）
```

> **fully furnished** = 拎包入住，什么都不需要买
> **limited furniture** = 可能只有床和基本电器，没有沙发/冰箱等

### 五、furniture vs furnished

注意区分：

```
furniture (n.)  → 家具（名词）
furnished (adj.) → 带家具的（形容词）
furnish (v.)    → 配备家具（动词）

✅ furniture: desk, chair, sofa, TV, fridge, bed...
✅ The apartment is fully furnished.
✅ It comes with furniture.
✅ I need to buy some furniture.
```

### 六、描述公寓的句型

```
It's a two-bedroom apartment.                  → 两室公寓。
It comes with a garage.                        → 带车库。
It's near public transportation.               → 靠近公交。
It's spacious and bright.                      → 宽敞又明亮。
It's close to my company.                      → 离公司近。
It's a little far from the city center.        → 离市中心有点远。
```

### 七、比较两个公寓

```
I prefer apartment A because it's cheaper.
→ 我更喜欢A公寓，因为它更便宜。

Apartment B is more spacious, but it's far from the subway.
→ B公寓更宽敞，但离地铁远。

A is closer to public transportation.
→ A更靠近公共交通。
```

**比较句型**：

```
A is cheaper than B.              → A比B便宜。
B is more spacious than A.        → B比A更宽敞。
A is closer to my company.        → A离我公司更近。
A is the best choice for me.      → A对我来说是最好的选择。
```

### 八、完整租房对话

**询问看房：**

```
A: Hi, I'm calling about the apartment for rent.
B: Yes, how can I help you?

A: How much is the rent?
B: It's £1,600 per calendar month.

A: How big is it?
B: It's a two-bedroom apartment, about 75 square meters.

A: Is it furnished?
B: Yes, it's fully furnished. You don't need to buy anything.

A: Is it near public transportation?
B: Yes, it's very close to the subway station, just a 5-minute walk.

A: That sounds great. Can I come to see it?
B: Sure. How about this Saturday?
```

**比较两个公寓：**

```
A: I'm trying to decide between apartment A and B.
B: What do you like about each one?

A: Well, apartment A is cheaper — only £1,200 a month.
   But apartment B is more spacious and closer to the subway.

B: Is apartment B furnished?

A: Yes, it's fully furnished. Apartment A only has limited furniture.

B: I think B is the better choice. You save money on furniture,
   and it's more convenient for commuting.

A: You're right. I'll go with apartment B.
```

### 九、"I've been thinking about it for a long time"

做决定时的实用表达：

```
I've been thinking about it for a long time.    → 我想了很久。
It's hard to choose. / I can't decide.          → 很难选。
There are some reasons why I chose it.           → 有几个我选它的理由。
First... Second... Third...                      → 第一…第二…第三…
I think it's the best choice for me.             → 我觉得这对我最好的选择。
```

### 十、数字读法（房租价格）

```
£1,600  → sixteen hundred (pounds)
         → one thousand six hundred (pounds)

£750   → seven hundred and fifty

£2,350 → twenty-three fifty
        → two thousand three hundred and fifty

$1,275 → twelve seventy-five
```

> 四位数价格在口语中常分为两组读：`1,600` → `sixteen hundred`
