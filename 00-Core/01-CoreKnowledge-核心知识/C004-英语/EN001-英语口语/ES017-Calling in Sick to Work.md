## 🎯 学习目标

- 用英语打电话给老板/上司请病假（call in sick）
- 掌握电话开场白："This is [name] calling" / "[Name] speaking"
- 用 "I feel awful" / "I'm not feeling very well" 描述身体不适
- 区分 "What's wrong?" 和 "What's the matter?" 的语气差异
- 理解 "What's wrong with you?" 的负面含义（≠ 单纯的 What's wrong?）
- 用 "I'm sorry, but I can't come to work today" 正式请假
- 用 "Sorry for the trouble" 表达对同事的歉意

## 📚 核心内容

### 一、打电话请病假的完整流程

```
1. 接电话方（老板）："[Name] speaking."        ← 自报姓名
2. 打电话方（你）：  "Hi, this is [name] calling." ← 表明身份
3. 老板察觉异常：    "What's wrong? You sound awful."
4. 你描述症状：      "I'm not feeling very well. I have a fever and a sore throat."
5. 你请假：          "I'm sorry, but I can't come to work today."
6. 老板回应：        "That's okay. Take it easy. Get well soon."
7. 你表示歉意：      "Sorry for the trouble."
```

### 二、电话开场白

| 角色 | 表达 | 说明 |
|------|------|------|
| 接电话方 | Maria Passos speaking. | 自报姓名 + speaking |
| 接电话方 | Hello, this is Maria. | 更随意的方式 |
| 打电话方 | This is Jabin calling. | 打电话方的标准自报 |
| 打电话方 | Hi, it's Jabin. | 如果对方认识你 |

```
✅ This is Jabin calling.      → 打电话时自报身份
❌ This is Jabin's calling.    → 不需要 's
```

### 三、察觉对方不适 — 询问句

当听到对方声音不对劲时：

| 表达 | 语气 | 使用场景 |
|------|------|----------|
| **What's the matter?** | 中性偏软 | 老板对员工，更温和 |
| **What's wrong?** | 直接 | 朋友/熟人之间 |
| **You sound awful.** | 关切 | 听到对方声音不对劲 |

### 四、"What's wrong?" vs "What's the matter?" 深度辨析

这是本课重点：

| 对比维度 | What's wrong? | What's the matter? |
|----------|---------------|-------------------|
| **词义** | wrong = 错的、坏的（负面） | matter = 事情、问题（中性） |
| **语气** | 更直接 | 更柔和 |
| **场景** | 朋友/熟人 | 老板/较正式场合 |

> 老师说：在请病假场景中，老板 Maria 选择 "What's the matter?" 而不是 "What's wrong?"，因为她是老板，想听起来更温和一些。

#### ⚠️ 关键陷阱："with you" 把中性变负面

```
What's wrong?           → 怎么了？（中性/关切）
What's wrong with you?  → 你有毛病吗？（强烈负面/责备）

What's the matter?      → 怎么了？（中性/温和）
What's the matter with you? → 你怎么回事？（负面/不满）
```

> **规则**：单独说 "What's wrong?" 或 "What's the matter?" 是关切的。加上 "with you" 就变成指责/不满的语气了。除非你真的在生气，否则不要加 "with you"。

### 五、描述身体不适

#### 基础表达

```
I feel awful.                    → 我感觉很糟糕。
I'm not feeling very well.       → 我感觉不太舒服。
I don't feel very well.          → 同上（不用 I'm）
```

#### 注意语法

```
✅ I'm not feeling well.         → be + 动词-ing（强调此刻状态）
✅ I don't feel very well.       → 一般现在时（也可以）
❌ I'm not feel well.            → be 后面要用 -ing
```

#### 描述具体症状

```
I have a fever and a sore throat.       → 我发烧了，喉咙也痛。
I feel so cold.                         → 我觉得很冷。
I've been coughing for three days.      → 我已经咳嗽三天了。
I've had a cough and a sore throat for three days. → 我咳嗽和喉咙痛已经三天了。
```

> **❌ 常见错误**：`I have coughing.` → coughing 是动词-ing 形式，不能这样用
> **✅ 正确**：`I have a cough.` 或 `I'm coughing a lot.`

### 六、正式请假句型

```
I'm sorry, but I can't come to work today.
→ 很抱歉，我今天不能来上班。

I'm afraid I won't be able to come in today.
→ 恐怕我今天无法来上班。（更正式/英式）

I'm sorry about work.
→ 对工作的事很抱歉。
```

> **"I'm sorry" 在这里的微妙含义**：不是真的在道歉，而是一种表达遗憾/不好意思的口语习惯，类似于中文的"不好意思啊"。

### 七、老板/同事的回应

| 表达 | 中文 |
|------|------|
| That's okay. | 没关系。 |
| Take it easy. | 放轻松，好好休息。 |
| Get well soon. | 早日康复。 |
| Don't worry about work. | 别担心工作。 |

### 八、表达歉意 — "Sorry for the trouble"

当请假会给同事带来不便时：

```
Sorry for the trouble.        → 抱歉添麻烦了。
Sorry about work.             → 对工作的事很抱歉。
I hope it's not too much trouble. → 希望不会太麻烦。
```

> 老师说：这是一个非常实用的商务英语短语（business chunk），不局限于请病假，任何给他人带来不便的场景都可以用。

### 九、"can't" 发音 — 英式 vs 美式

```
can't   → 英式：/kɑːnt/   （"ah"音）
        → 美式：/kænt/    （"æ"音，像 cat 的 a）

✅ I can't come to work.   → 两种发音都可以
```

### 十、"This is [name] calling" 的使用场景

这个句式不仅用于请病假，在所有电话场景中都很实用：

```
电话预约：    Hello, this is Jabin calling. I'd like to make an appointment.
电话咨询：    Hi, this is Jabin calling. I have a question about...
电话投诉：    Good morning, this is Jabin calling. I'd like to speak to the manager.
```

### 十一、voicemail 语音信箱留言

如果老板没接电话，需要留言：

```
Hello, this is Jabin calling.
I'm not feeling very well today. I have a fever and a sore throat.
I'm afraid I won't be able to come in today.
Sorry for the trouble. I'll keep you updated.
Please call me back when you can. Thank you.
```

### 十二、完整对话模板

**Calling in Sick:**

```
Boss:   Maria Passos speaking.

You:    Hi Maria, this is Jabin calling.

Boss:   Hi Jabin. What's the matter? You sound awful.

You:    I'm not feeling very well. I have a fever and a sore throat.
        I've been coughing for three days.

Boss:   I'm sorry to hear that.

You:    I'm sorry, but I can't come to work today.
        Sorry for the trouble.

Boss:   That's okay. Don't worry about work.
        Take it easy and get well soon.

You:    Thank you. I hope to be back soon.

Boss:   No rush. Just focus on getting better. Bye.

You:    Bye. Thank you.
```
