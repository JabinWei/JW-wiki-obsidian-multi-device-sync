## 🎯 学习目标

- 在服装店用英语与店员进行完整的购物对话
- 用英语询问尺码、面料、价格和试衣间位置
- 掌握购物场景的礼貌表达（I'd like to vs I want to）
- 学会用英语描述衣服的材质（cotton, polyester, denim, wool）
- 正确用英语表达价格（$29.99 的读法）
- 用英语为朋友挑选礼物并进行购买

## 📚 核心内容

### 一、购物核心词汇 (Shopping Vocabulary)

#### 尺码 (Sizes)

| 英文 | 中文 |
|------|------|
| small (S) | 小号 |
| medium (M) | 中号 |
| large (L) | 大号 |

#### 面料/材质 (Fabrics/Materials)

| 英文 | 中文 | 说明 |
|------|------|------|
| **cotton** | 棉 | 最常见的天然面料 |
| **polyester** | 涤纶/聚酯纤维 | 合成面料，衣服标签上常见 |
| **denim** | 牛仔布 | 牛仔裤的面料 |
| **wool** | 羊毛 | 来自 sheep 或 goats |

> **老师的讲解：** Fabric 专指衣物面料（布料），而 material 范围更广（可以指任何材料，如金属、塑料等）。在购物场景中两者有时可互换，但 fabric 更精确。

> **发音提示：** polyester 是较难读的词，音标为 /ˌpɒliˈestə/（英式）或 /ˌpɑːliˈestər/（美式）。

#### 价格相关

| 英文 | 中文 |
|------|------|
| cheap | 便宜的 |
| expensive | 昂贵的 |
| on sale | 打折中 |
| promotion | 促销活动 |
| It's a good price. | 价格不错。 |
| That's quite cheap. | 相当便宜。 |

#### 店铺相关

| 英文 | 中文 | 说明 |
|------|------|------|
| clothing store / clothing shop | 服装店 | — |
| sales clerk / sales assistant | 店员/销售助理 | 多種说法 |
| customer | 顾客 | 注意发音，不要漏掉 to |
| fitting room | 试衣间 | **比 changing room 更常用** |
| changing room | 更衣室 | 也可以用，但 fitting room 更普遍 |
| in stock | 有库存 | We have it in stock. |

### 二、购物四大核心问句

在服装店购物时，有四个最核心的问题需要掌握：

| # | 问句 | 回答模板 | 用途 |
|---|------|----------|------|
| 1 | **What size is it?** | It's small / medium / large. | 询问尺码 |
| 2 | **What's it made of?** | It's made of cotton / polyester / denim / wool. | 询问面料 |
| 3 | **How much is it?** | It's $29.99. / It's cheap. / It's expensive. | 询问价格 |
| 4 | **Where are the fitting rooms?** | They're on the second floor. | 询问试衣间 |

**面料比例的表达：**

```
It's made of 75% cotton and 25% polyester.
→ 它由 75% 的棉和 25% 的涤纶制成。

It's made of cotton.                  →  全棉的。
```

### 三、价格读法 — $29.99 怎么说

这是一个重要的文化差异点：

| 写法 | 正确读法 | 错误读法 |
|------|----------|----------|
| $29.99 | **twenty-nine ninety-nine** | twenty-nine dot ninety-nine |
| $35.89 | **thirty-five eighty-nine** | thirty-five point eighty-nine |

> **老师的讲解：** 在说价格的时候，不要说 "dot" 或 "point"。直接分开读数字即可。但在网址中（如 www.example.com），"." 才读作 "dot"。

**标准价格读法：**
- $29.99 = "twenty-nine ninety-nine"
- $75.00 = "seventy-five dollars"
- $150.00 = "one hundred fifty dollars" 或 "one fifty"
- $50.00 = "fifty dollars"

### 四、购物对话中的礼貌表达

这是本课格外强调的要点。对服务人员（service people）说话时，措辞的礼貌程度很重要：

| 语境 | 推荐表达（礼貌） | 不太推荐 |
|------|-----------------|----------|
| 进店说明需求 | **I'm looking for a jacket.** | I want a jacket. |
| 表达想要某物 | **I'd like to try the white one.** | I want to try the white one. |
| 决定购买 | **I'll go with the white one.** | I want to choose the white one. |
| 决定购买 | **I'll take the white one.** | — |
| 请求试穿 | **Could I try a large one?** | Can I try a large? |

> **老师的讲解：** "I want to" 对家人朋友说没问题，但和服务人员说话时，用 "I'd like to" 更自然、更礼貌。"I'll go with" 和 "I'll take" 也是非常地道的表达。

#### "I want to" vs "I'd like to" 对比

```
对妈妈/朋友：  ✅ I want to buy this jacket.
对店员：      ✅ I'd like to buy this jacket.  （更礼貌自然）
```

### 五、"Look for" vs "Find" vs "Try to Find"

```
✅ I'm looking for a denim jacket.        →  我在找一件牛仔夹克（标准表达）
✅ I'm trying to find a yellow jacket.    →  我在试着找一件黄色夹克（强调难找）
❌ I find a jacket.                       →  语法不对
✅ I found a jacket.                      →  我找到了一件夹克（已经找到了）
✅ I want to find a jacket.               →  我想找一件夹克（需要加 to）
```

> **老师的讲解：** 进店时不要说 "I want a jacket" 或 "I need a jacket"——太直接了。标准说法是 "I'm looking for a jacket." 如果你在找一个比较难找的款式（比如特定颜色），可以说 "I'm trying to find a yellow jacket."

### 六、"Quite" — 程度副词

"Quite" 是一个高频但容易被忽略的程度副词，相当于 "very" 或 "really"：

```
That's quite cheap.        →  相当便宜。
= That's very cheap.
= That's really cheap.

He's quite serious.        →  他相当严肃。
That's quite expensive.    →  相当贵。
```

> **注意：** "quite" 后面直接接形容词。不要说 "a quite cheap"。

### 七、"Look Good on Someone" — 穿在某人身上好看

这是一个非常地道的表达：

```
The black one looks good on me.     →  黑色的我穿好看。
It looks good on you.               →  你穿很好看。
This jacket looks good on him.      →  这件夹克他穿好看。

❌ The black color is very suitable for me.  →  虽然语法对，但不地道
✅ The black one looks good on me.           →  自然地道
```

> **结构：** [衣物] + looks good on + [人]

### 八、"Fit" — 合身

```
The white one fits me.         →  白色的那件合身。
Does it fit you?               →  合身吗？
It fits me well.               →  很合身。

❌ The white one is fitting me.     →  一般不用进行时
✅ The white one fits me.           →  简单现在时
```

> **发音提示：** fits 不是 "feets"，是 /fɪts/。

### 九、"On Sale" vs "Promotion"

| 表达 | 含义 |
|------|------|
| **on sale** | 打折中/特价中 |
| **promotion** | 促销活动 |
| **It's on sale.** | 它在打折。 |
| **There's a promotion.** | 有促销活动。 |

```
You are in luck. This T-shirt is currently on sale.
→ 你真走运。这件T恤现在正好在打折。

Usually it costs about 150, but now it's on sale for only 100.
→ 通常大约150元，但现在打折只要100元。
```

### 十、完整购物对话模板

#### 场景一：为自己购物

```
Sales Clerk:  Good morning, sir. How can I help you today?
Customer:    Hi, I'm looking for a denim jacket.
Sales Clerk:  What color are you looking for?
Customer:    I think black. 
Sales Clerk:  Well, I'm sorry, we don't have the black one right now.
              But I can show you the grey one and the white one.
              These are all in size large. What do you think?
Customer:    I'd like to try the white one.
             Where are the fitting rooms?
Sales Clerk:  We have two fitting rooms. One is on the second floor,
             and the other one is on the third floor.
Customer:    OK, I'll go to the second floor to try it on.
             ... (after trying)
Customer:    The white one fits me. What's it made of?
Sales Clerk:  Let me check. It's made of 75% cotton and 25% polyester.
Customer:    How much is it?
Sales Clerk:  You are very lucky! This jacket is on sale. Only $50.
Customer:    That's a good price. I'd like to buy one.
Sales Clerk:  Great! Would you like it to be wrapped?
Customer:    No, thank you. That's all.
```

#### 场景二：为朋友买礼物

```
Sales Clerk:  Good morning, sir. How can I help you?
Customer:    Hi, I'd like to find a new T-shirt as a birthday present 
             for my friend, Alex.
Sales Clerk:  Great. What color are you looking for?
Customer:    I think a blue one.
Sales Clerk:  Sure, we do have blue shirts. What size do you need?
Customer:    He is very tall and quite thin. So I think medium size.
Sales Clerk:  You are in luck. We do have some medium size here in stock.
             How about this one? What do you think?
Customer:    It looks good. How much is it? Is it on sale?
Sales Clerk:  Yes! This T-shirt is currently on sale. You can get it for $100.
             Usually it costs about $150.
Customer:    That sounds great. I think it's a good price.
             I'd like to get one.
Sales Clerk:  Would you like it to be wrapped? (It's a present, right?)
Customer:    Oh, yes, please.
```

### 十一、实用短句速查

|------|------|----------|
| How can I help you? | 有什么可以帮您的？ | 店员开场白 |
| I'm looking for... | 我在找... | 顾客说明需求 |
| What color are you looking for? | 您找什么颜色的？ | 店员询问颜色 |

### 十二、用手机展示图片

当不知道如何用英文描述某件衣服时，可以直接用手机展示图片：

```
✅ Just show your phone and say: "It looks like this."
✅ Hey, I'm looking for something like this. (拿出手机展示图片)

❌ Please, my phone.  (语法对但表达不自然)
```

### 十三、购物流程总结

```
1. 进店 → How can I help you? / I'm looking for...
2. 颜色 → What color are you looking for? / I think black.
3. 尺码 → What size are you? / Large, please. / Could I try a large one?
4. 试穿 → Where are the fitting rooms? / I'd like to try this on.
5. 面料 → What's it made of? / It's made of cotton.
6. 价格 → How much is it? Is it on sale?
7. 决定 → I'll go with this one. / That's a good price.
8. 购买 → I'd like to buy it. / Would you like it to be wrapped?
```
