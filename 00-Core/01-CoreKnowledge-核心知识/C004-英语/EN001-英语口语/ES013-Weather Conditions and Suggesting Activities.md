## 🎯 学习目标

- 用英语描述天气状况（pleasant, awful, terrible, wonderful, freezing 等）
- 根据天气条件提出活动建议（How about...? / What about...?）
- 学会回应建议：接受（That's a great idea!）、婉拒（Thanks, but...）
- 掌握 "freezing" 表示"极冷"的用法
- 区分 "go to + 地点" 和 "go on + 活动"（go on a picnic）

## 📚 核心内容

### 一、天气条件描述词汇（进阶）

除了基础的 sunny/rainy/windy 之外，用这些词来描述天气的"好坏程度"：

| 形容词 | 中文 | 程度 | 例句 |
|--------|------|------|------|
| **wonderful** | 极好的 | ⭐⭐⭐⭐⭐ | The weather is wonderful today! |
| **great** | 很好的 | ⭐⭐⭐⭐ | It's great weather for a picnic. |
| **pleasant** | 宜人的 | ⭐⭐⭐ | It's pleasant outside. |
| **nice** | 不错的 | ⭐⭐⭐ | The weather is nice. |
| **bad** | 不好的 | ⭐⭐ | The weather is bad. |
| **awful** | 很糟糕的 | ⭐ | It's awful outside. |
| **terrible** | 极差的 | ⭐ | The weather is terrible. |
| **freezing** | 极冷的 | ❄️❄️❄️ | It's freezing! |

> **freezing** = very very very cold。字面意思是"冰冻的"，口语中表示"冷死了"。
> 
> 老师说："Freezing means it's very very very cold. Super super cold."

### 二、基于天气的活动词汇

#### 户外活动

| 活动 | 英文 | 搭配动词 |
|------|------|----------|
| 去海滩 | go to the beach | go to |
| 去跑步 | go running | go + -ing |
| 在公园跑步 | go running in the park | go + -ing + place |
| 野餐 | have a picnic / go on a picnic | have / go on |
| 玩纸牌 | play card games / play a game of cards | play |

#### 室内活动

| 活动 | 英文 |
|------|------|
| 待在家 | stay in / stay at home |
| 看电影 | watch a movie |
| 看书 | read a book |
| 玩电子游戏 | play video games |

### 三、"go to" vs "go on" 的区别

```
go to + 地点      → 去某个地方
go on + 活动      → 去进行某项活动

go to the beach   ✅  （去海滩这个地方）
go to a picnic    ❌  （picnic 不是地点）
go on a picnic    ✅  （去野餐这项活动）
```

> 老师说："Go to a place — like you go to work, you go to office. But go on a picnic."

### 四、提出活动建议

#### 两种提议句型

| 句型 | 语气 | 例句 |
|------|------|------|
| **How about...?** | 建议 | How about going to the beach? |
| **What about...?** | 建议/替代 | What about watching a movie? |
| **We should...** | 较强势 | We should go out. |
| **Let's...** | 直接提议 | Let's have a picnic. |

**注意**：`How about` / `What about` 后面接**动词 -ing** 或**名词**：

```
How about going to the park?  ✅  (动词-ing)
How about a picnic?           ✅  (名词)
How about go to the park?     ❌
```

### 五、回应建议

#### 接受建议

| 表达 | 语气 |
|------|------|
| That's a great idea! | ⭐⭐⭐ 热烈赞同 |
| That's a good idea. | ⭐⭐ 赞同 |
| Sounds good! | ⭐⭐ 口语化赞同 |
| Okay, let's do that. | ⭐⭐ 同意 |

#### 婉拒/不确定

| 表达 | 语气 |
|------|------|
| I'm not sure. | 不太确定 |
| Thanks, but... | 感谢但婉拒 |
| I don't think so. | 直接不认同 |
| That's a good idea, but... | 先肯定再婉拒 |

> **礼貌婉拒模式**：先说好的方面，再用 `but` 转折：
> ```
> That's a good idea, but I'm a bit tired today.
> That sounds fun, but the weather is terrible.
> ```

### 六、基于天气的完整建议对话

**对话一：天气好 → 户外活动**

```
A: The weather is wonderful today!
B: Yes, it's so pleasant outside.

A: How about going to the beach?
B: That's a great idea! Let's go.

A: Should we have a picnic there?
B: Sounds good! I'll bring some food.
```

**对话二：天气差 → 室内活动**

```
A: The weather is terrible today. It's freezing outside!
B: I know. It's so cold and rainy.

A: What about staying in and watching a movie?
B: That's a good idea. I don't want to go out in this weather.

A: How about a card game after the movie?
B: Sure! That sounds fun.
```

**对话三：不确定 → 给出替代方案**

```
A: How about going running in the park?
B: I'm not sure. The weather is awful today.

A: What about playing card games at home instead?
B: That's a great idea! Let's do that.
```

### 七、"awful" 和 "terrible" 的用法

这两个词不止用于天气，是非常通用的负面形容词：

```
The weather is awful.        → 天气糟透了。
The food was awful.          → 食物难吃极了。
I had a terrible day.        → 我今天过得很糟糕。
The traffic is terrible.     → 交通堵死了。
```

### 八、"based on" — 基于…的表达

```
We choose activities based on the weather conditions.
→ 我们根据天气条件来选择活动。

Based on the weather, we should stay in today.
→ 基于天气，我们今天应该待在家。
```
