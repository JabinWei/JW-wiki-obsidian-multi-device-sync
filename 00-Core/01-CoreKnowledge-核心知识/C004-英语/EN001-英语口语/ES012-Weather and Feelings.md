## 🎯 学习目标

- 用英语描述天气（rainy, sunny, windy, cold, stormy, warm, hot 等）
- 掌握询问天气的两种方式："What's the weather like?" 和 "How's the weather?"
- 说出四个季节的英文名称（spring, summer, fall/autumn, winter）
- 了解 Small Talk（闲聊）中天气话题的重要性
- 区分 "hot" 和 "warm" 在描述天气时的语用差异
- 用英语描述不同城市/季节的天气特征

## 📚 核心内容

### 一、天气基础词汇

| 形容词 | 中文 | 对应名词 |
|--------|------|----------|
| sunny | 晴朗的 | sun |
| rainy | 下雨的 | rain |
| windy | 有风的 | wind |
| cloudy | 多云的 | cloud |
| stormy | 暴风雨的 | storm |
| snowy | 下雪的 | snow |
| foggy | 有雾的 | fog |
| cold | 冷的 | — |
| hot | 热的 | — |
| warm | 温暖的 | — |
| cool | 凉爽的 | — |
| dry | 干燥的 | — |
| wet | 潮湿的 | — |

> **构词规则**：大多数天气形容词 = 名词 + y（cloud → cloudy, wind → windy, storm → stormy）
> 例外：sun → sunny（双写 n）

### 二、四个季节

| 季节 | 英文 | 英式/美式 |
|------|------|-----------|
| 春天 | spring | — |
| 夏天 | summer | — |
| 秋天 | fall | 美式英语 |
| 秋天 | autumn | 英式英语 / 正式 |
| 冬天 | winter | — |

> 老师提示：在美国英语中，用 `fall` 比 `autumn` 更常见。`autumn` 更偏正式或英式用法。

### 三、询问天气的两种方式

```
What's the weather like?   → 天气怎么样？
What's the weather like in London?  → 伦敦天气怎么样？

How's the weather?          → 天气如何？（更口语）
How's the weather in Dubai? → 迪拜天气如何？
```

**回答模式：**

```
It's + 天气形容词.
It's sunny and hot.
It's cold and rainy.
```

**不同季节的天气描述：**

```
What's the weather like in fall in Shanghai?
→ It's stormy and cold.

How's the weather in summer in your city?
→ It's sunny and hot.

What's the weather like in London?
→ It's cold and rainy.

How's the weather in Dubai?
→ It's hot and sunny.
```

### 四、Hot vs Warm — 一个重要的语用差异

这是一个非常实用的文化/语用知识点：

| 词 | 字面意思 | 实际语用 |
|----|----------|----------|
| **hot** | 热 | 有时听起来太强烈，像在抱怨 |
| **warm** | 温暖 | 母语者更常用，即使实际温度很高 |

**老师的亲身经验**：在中国深圳，夏天非常热（37-38°C），但她的外国同事总是说 "It's very warm today." 而不是 "It's so hot." 用 `warm` 听起来更轻松、更自然，比 `hot` 少了抱怨的语气。

```
✅ It's warm and sunny today.  → 今天天气暖和晴朗。（更自然地道）
✅ It's hot today.             → 今天很热。（也可以，但比较直接）
```

> **学习启示**：不要只记单词与中文的一对一映射。`warm` ≠ 只有"温暖"，在实际使用中它常常能替代 `hot`。

### 五、"What's your favorite season?"

```
What's your favorite season?
→ 你最喜欢哪个季节？

I love winter because it's snowy.
→ 我喜欢冬天，因为会下雪。

I like spring because it's warm.
→ 我喜欢春天，因为很温暖。

My favorite season is fall.
→ 我最喜欢的季节是秋天。
```

### 六、Weather 作为 Small Talk 话题

在英语文化中，天气是标准的 **small talk（闲聊/寒暄）** 话题：

```
Small talk topics:
- Weather          → 天气（最常见、最安全的话题）
- Weekend plans    → 周末计划
- Hobbies          → 爱好
- Travel           → 旅行
```

> 老师说："Whenever you do English or Chinese or any other languages, you have to do small talk. It's very important. Weather would be one of the small talk topics."

**Small talk 中的天气用语：**

```
Nice weather we're having!      → 天气真好啊！
It's beautiful outside today.   → 今天外面天气真好。
Terrible weather, isn't it?     → 天气真糟糕，对吧？
Looks like it's going to rain.  → 看起来要下雨了。
It's freezing today!            → 今天冷死了！
It's burning hot!               → 热得像火烧一样！
```

### 七、描述不同城市天气的练习框架

```
What's the weather like in [城市]?

In spring, it's [形容词] and [形容词].
In summer, it's [形容词] and [形容词].
In fall, it's [形容词].
In winter, it's [形容词] and [形容词].
```

**示例 — 描述上海天气：**

```
What's the weather like in Shanghai?

In spring, it's warm and sometimes rainy.
In summer, it's very hot and sunny.
In fall, it's cool and windy.
In winter, it's cold and sometimes snowy.
```

### 八、Stormy — 暴风雨天气

```
It's storming outside.                         → 外面在暴风雨。
Looks like we can't go to the beach today.      → 看来我们今天不能去海滩了。
Do you have stormy weather in Shanghai?         → 上海有暴风雨天气吗？
```

### 九、表达温度的对话

```
A: How's the weather there for you?
B: It's sunny and cloudy.

A: Is it hot?
B: Yes, very hot.

A: How hot is hot?
B: 37, almost 38 degrees!
   I'm like burning here!

A: Wow, that's really hot. Here it's 28 degrees.
B: 28 sounds really nice. I'm so jealous!
```

**温度相关表达：**

```
I'm burning!         → 我要热死了！
I'm freezing!        → 我要冻死了！
It's like a hot fire here.  → 这里热得像火炉一样。
```

### 十、Weather 特定语法结构

#### "It's + 天气动词-ing"

```
It's raining.       → 正在下雨。
It's snowing.       → 正在下雪。
It's storming.      → 正在刮暴风雨。
```

> 注意：只有部分天气词有这种动词用法。说"天气是晴朗的"只能用 `It's sunny.` 不能 `It's sunning.`

#### "It's + 天气形容词"

```
It's sunny.     → 天气晴朗。
It's rainy.     → 天气多雨。
It's windy.     → 天气有风。
```

#### "There is/are + 天气名词"

```
There is a storm coming.        → 暴风雨要来了。
There is heavy rain outside.    → 外面下大雨。
```
