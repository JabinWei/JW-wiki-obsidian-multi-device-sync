# 计算机知识导论

以《大话计算机——计算机系统底层架构原理极限剖析》（冬瓜哥 / 张冬 著，清华大学出版社，全三卷）为主要参考，整理属于自己的计算机导论知识体系。

> **定位：底层原理的汇总，不是应用。** 这本书讲的是计算机**怎么工作**——从晶体管一路讲到操作系统、多媒体、加速计算、甚至 AI 的硬件加速，全部是「底层架构原理」视角。它看问题的角度与 C002 人工智能、C005 全栈开发**不同**：那两边已经站在「怎么使用」的层面，这里只是把地基打牢。因此本纲**完整收录书中所讲的一切底层原理主题**，不做取舍。
>
> **拆分原则**：原书各章篇幅悬殊（第 2 章 52 页 vs 第 10 章 282 页），故大章拆分、小章合并，把每条笔记体量拉平到约 50–95 页。

## 大纲总览

```
             【阶段一】硬件地基                           【阶段二】CPU 与程序
晶体管→逻辑门→组合/时序电路→存储程序·芯片 → 流水线/乱序 → 指令/汇编/机器码
                                                                     │
           【阶段四】操作系统与智能   ←   【阶段三】系统全家桶   ←─────┘
 OS→进程/调度/内存/文件→生态→ML/AI   缓存·多核 · I/O · 声音图像 · 加速计算
```

四个阶段，从「开关」一路搭到「智能」，全程不换视角——都是底层原理。
