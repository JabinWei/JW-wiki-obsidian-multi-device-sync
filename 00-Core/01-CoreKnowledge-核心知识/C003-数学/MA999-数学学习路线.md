## 🎯 学习目标

建立从零基础到能理解 AI/ML 数学原理的知识体系，兼顾实用性（能满足深度学习论文阅读）和兴趣延展（数论/图论/拓扑等）。

---

## 📖 阶段 0：捡回中学基础（2-3 周）

> 如果初中/高中数学忘完了，从这里开始。不需要重读六年，只捡 CS/AI 真正用到的。

### 成年人补数学的策略：按需补，不从头刷

核心思路不是"补完基础再学正课"，而是**正课遇到什么不会就去查什么**：

```
读微积分 → 发现三角函数看不懂 → 花 1 小时补三角函数 → 继续读
读线性代数 → 发现方程组不会解 → 花半小时补一下 → 继续读
```

**实际需要的 vs 不需要操心的**：

| 你需要的 | 不需要操心的 |
|---------|------------|
| 函数是什么、怎么画图 | 三角函数恒等变换（积化和差） |
| 指数运算（$x^a \times x^b = x^{a+b}$） | 圆锥曲线（椭圆双曲线） |
| 对数运算（$\log(ab) = \log a + \log b$） | 复数运算 |
| 一次/二次方程怎么解 | 排列组合公式推导 |
| sin/cos 的定义和图像 | 平面几何证明 |

### 推荐资源

| 资源                                    | 说明                                                            |
| ------------------------------------- | ------------------------------------------------------------- |
| **《Engineering Mathematics》(Stroud)** | 从四则运算讲到傅里叶变换。每章半页讲解 + 大量练习，做着做着就会了。读到第 20 章即覆盖 CS 所需全部基础，一本到底 |
| **《Foundation Mathematics》(Stroud)**  | 上一本的前半部分，只覆盖到预科水平——如果觉得 Engineering Mathematics 起点还是高了，先看这本   |
| **Khan Academy（可汗学院）**                | 当工具书用，不要从头刷课程列表。遇到具体概念直接搜索看 5 分钟视频                            |
| 已有笔记                                  | [[CA001-函数]]                                                  |

> 成年人补基础最大的坑就是"先看完 Khan Academy 的高中课程再开始"——会花三个月看 200 个视频，大多数内容 CS 根本用不上。**先下水，缺什么补什么**，效率高得多。

## 📖 阶段 1：核心数学基础（4-5 个月）

> 前三门（微积分/线代/概率）是 AI/ML 的数学基石；离散数学是 CS 的通用基础（算法、数据结构、数据库等）。

### 1.1 微积分

| 书籍 | 说明 |
|------|------|
| **《Calculus》(Gilbert Strang)** | MIT 招牌教材，强调理解和应用而非证明，非常适合 CS 学生。配套视频课在 MIT OCW 免费看 |
| 《普林斯顿微积分读本》 | 中文修订版，ISBN 9787115435590，如果更喜欢中文阅读 |
| **《Calculus Made Easy》(Thompson)** | 1910 年的薄书，用最直白语言讲"微积分到底在干什么"——适合快速建立直觉后再看正式教材 |
| **《Vector Calculus, Linear Algebra, and Differential Forms》(Hubbard)** | 多元微积分 + 线性代数融合，直接对标 ML 中的梯度、雅可比矩阵、海森矩阵 |

> CS 首选 Strang。Hubbard 适合学完线代后回来看多元部分。

**AI/ML 用到**：导数→梯度下降、链式法则→反向传播、偏导数→多变量优化

**学习重点**：极限 → 导数 → 链式法则 → 偏导数与梯度 → 基本积分

### 1.2 线性代数

| 书籍 | 说明 |
|------|------|
| **Gilbert Strang《线性代数及其应用》** | MIT 经典教材，Strang 的讲课比书写得还清楚，建议配合 OCW 视频 |
| **《Linear Algebra Done Right》(Axler)** | 从线性变换出发（而非矩阵），帮你建立几何直觉。比传统教材更适合理解 PCA、SVD 的"为什么"。免费电子版 |
| **《Coding the Matrix》(Klein)** | 用 Python 代码讲线性代数——适合"看不进去纯公式"的时候 |
| **《Matrix Analysis and Applied Linear Algebra》(Meyer)** | 偏应用，配大量 MATLAB 代码。关心"怎么算"而非"怎么证明"时选这本 |

> 入门首选 Strang 视频 + 教材。想加深理解看 Axler，想手写代码看 Klein。

**AI/ML 用到**：矩阵乘法→神经网络前向传播、特征值/特征向量→PCA 降维、向量空间→Embedding

**学习重点**：向量 → 矩阵运算 → 线性方程组 → 行列式 → 特征值与特征向量

### 1.3 概率与统计

| 书籍 | 说明 |
|------|------|
| **《概率导论》(Bertsekas)** | 比传统教材薄，直观好用 |
| **《Probability and Statistics for Computer Scientists》(Baron)** | 针对 CS 学生写的，例子全是算法分析、网络延迟、排队论，不是生物/金融场景 |
| **《Think Bayes》(Downey)** | 用 Python 代码代替公式讲贝叶斯推断，Think 系列一贯的风格。免费 |

> CS 视角首选 Baron。如果想用代码理解贝叶斯，看 Downey。

**AI/ML 用到**：贝叶斯定理→朴素贝叶斯、最大似然估计→损失函数、分布→生成模型

**学习重点**：概率基础 → 条件概率 → 贝叶斯定理 → 随机变量 → 常见分布 → 最大似然估计

### 1.4 离散数学

> 数学系可能只是选修，但**离散数学是 CS 的核心基础课**——直接对应算法、数据结构、数据库、编译原理。

| 书籍 | 说明 |
|------|------|
| **《Mathematics for Computer Science》(Lehman, Leighton / MIT)** | MIT 6.042J 课程讲义，全书免费。离散数学 + 概率 + 图论，覆盖面广，习题极好 |
| **《Concrete Mathematics》(Graham, Knuth, Patashnik)** | 经典中的经典。把微积分、组合、数论"离散化"——Knuth 写的东西不会差。稍硬，适合有基础后读 |
| **《离散数学及其应用》(Rosen)** | 百科全书式教材，适合当参考书查阅 |

> 首选 MIT 6.042J 讲义。Rosen 当工具书查缺补漏。

**CS 用到**：图论→网络/路径规划、组合→算法复杂度、数理逻辑→数据库/编译、布尔代数→数字电路

## 📖 阶段 2：进阶数学（2-3 个月，按需选修）

| 主题 | 用到什么 | 推荐书 |
|------|----------|--------|
| 信息论 | 交叉熵损失、KL 散度、熵 | **《Information Theory, Inference, and Learning Algorithms》(MacKay)** — 免费 PDF，把信息论、贝叶斯、神经网络串在一起，物理学家写的，视角独特 |
| 凸优化 | SGD、Adam、约束优化 | **《Convex Optimization》(Boyd)** — 经典教材，作者 Stanford 有配套视频课。另有 **《Algorithms for Optimization》(Kochenderfer)** — 全是 Julia 代码，算法驱动而非定理驱动 |

## 🎨 兴趣延展（自由探索）

> AI 基础学完后，按兴趣选方向

| 方向 | 为什么有趣 | 入门书 |
|------|-----------|--------|
| **图论** | 知识图谱、社交网络、推荐系统 | 《图论导引》(West) |
| **组合数学** | 计数、排列、算法复杂度 | 《具体数学》(Knuth) — 程序员圣经 |
| **数论** | 密码学基石、RSA 原理、素数之美 | 《数论导引》(Hardy) |
| **抽象代数** | 对称性、群论→密码学 | 《近世代数》(Rotman) |
| **拓扑学** | "甜甜圈=咖啡杯"的柔性几何 | 《拓扑学基础》(Munkres) |
| **微分几何** | 流形学习、深度学习几何视角 | 《微分几何》(do Carmo) |

## 🗺️ 推荐学习顺序

```
《数学之美》(通识感觉)
    ↓
阶段 0：捡回中学基础（Stroud / 可汗学院，2-3 周）
    ↓
阶段 1.1：微积分（Strang《Calculus》，1 个月）
    ↓
阶段 1.2：线性代数（Strang 视频 + 教材，1 个月）
    ↓
阶段 1.3：概率统计（Bertsekas / Baron，1 个月）
    ↓
阶段 1.4：离散数学（MIT 6.042J 讲义，1 个月）
    ↓
（此时已能读懂 80% 的 ML 论文数学部分）
    ↓
阶段 2：信息论/凸优化（按需选修）
    ↓
兴趣延展：图论/组合/数论...（自由探索）
```

> 如果目标只是快速上手 ML，可以直接看 **《Mathematics for Machine Learning》(Deisenroth)**——免费 PDF，一本覆盖线性代数 + 微积分 + 概率，篇幅适中，适合快速建立框架。
