# 个人 IP 形象「阿砚」设定文档

![[IP形象-阿砚-定稿v21.png]]

> 这是后续所有插图、封面、表情包的基准形象。生成新图时必须严格遵循本设定，保证角色一致性。
> **面部特征尤其要锁定**——见第二节「面部锚点」。

---

## 一、角色基本信息

- **名字**：阿砚（暂用，可改）
- **身份**：年轻程序员 / 开发者
- **气质**：又酷又可爱 —— 深色系穿搭有科技潮酷感，但 Q 版比例、圆脸大眼、腮红保持可爱
- **性格**：淡定微笑、聪明、亲切，不咧嘴大笑

---

## 二、面部锚点（每次生成都必须严格一致）

> ⚠️ **这一节是一致性的关键**。之前几次生成都在脸上飘（眉毛粗细、眼大小、嘴形），所以把下面每一项都写成 prompt 关键词，每次生成时整段复制粘贴。

### 面部特征清单

| 部位 | 精确设定 | Prompt 关键词（英文） |
|------|---------|---------------------|
| **脸型** | 圆胖 Q 版脸，下巴短圆，没有尖锐线条 | round chubby face, soft jawline, no sharp angles |
| **眼睛大小** | 大而圆，眼高约占脸高 1/3，两眼间距约 1 个眼宽 | big round eyes, eyes ~1/3 of face height, eyes spaced one eye-width apart |
| **眼睛形状** | 正圆形，上眼睑平直，下眼睑圆润，没有睫毛 | perfectly round eyes, flat upper lid, round lower lid, NO eyelashes |
| **瞳孔颜色** | 青蓝/teal 色，每只眼睛 2 个白色高光点（一大一小） | teal-blue iris, two white highlight dots per eye (one big, one small) |
| **眉毛** | 短而整齐的**剑眉**，浓度中等偏深，略上扬（一点少年气），不是粗平眉 | neat slightly thick boyish sword eyebrows, subtle upward tilt, medium-dark |
| **鼻子** | 极小，几乎不可见，只有一个淡色小点 | tiny nose, just a small dot, barely visible |
| **嘴** | 淡淡的**上扬微笑**（closed mouth smile，闭着嘴），嘴角微微上翘，**不张开、不露齿、不咧嘴** | small closed-mouth gentle smile, subtle upturned corners, NO open mouth, NO teeth |
| **腮红** | 两团**圆形桃粉色腮红**，位置在眼睛正下方偏外侧，边界柔和晕开，不浓 | round soft peachy blush circles under eyes, gently blended, light intensity |
| **耳朵** | 小而圆，露出，耳内淡粉色 | small round visible ears, light pink inner ear |
| **肤色** | 暖白偏粉 | warm fair skin with pink undertone |
| **面部装饰** | ❌ 无眼镜、❌ 无脸颊印/纹身、❌ 无痣、❌ 无疤 | NO glasses, NO cheek marks, NO facial tattoos, NO freckles |

### 面部锁定 Prompt（生成时整段复制）

```
chibi face: round chubby face with soft jawline;
big perfectly round teal-blue eyes, eyes ~1/3 face height,
spaced one eye-width apart, two white highlight dots per eye;
neat slightly thick boyish sword eyebrows with subtle upward tilt;
tiny barely-visible nose;
small closed-mouth gentle smile with upturned corners, NO open mouth, NO teeth;
round soft peachy blush circles under eyes;
small round visible ears; warm fair skin;
NO glasses, NO cheek marks, NO facial decorations
```

## 三、发型（不可变）

- **款式**：短寸头 crew cut，**两侧和后颈很短**，**头顶有刺刺蓬松感**（不是贴头皮平寸）
- **发色**：深藏青近黑蓝（deep indigo-navy，不是纯黑、不是浅蓝）
- **刘海**：无刘海，**额头全露**
- **呆毛**：❌ 不要单独的呆毛，头顶刺刺短发整体自然翘起即可

Prompt 关键词：
```
short crew cut, spiky textured top hair, deep indigo-navy color,
short shaved sides, forehead fully visible, NO bangs, NO ahoge
```

## 四、服装与配饰（不可变）

### 主穿搭
- **连帽衫**：深藏青靛蓝色（indigo navy），oversize 宽松，**帽子戴在头上**（短刺刺短发从帽檐前翘出来），白色圆绳抽绳，前侧袋鼠口袋
- **龙纹位置（v21 调整）**：荧光青/电光青的酷炫龙头图腾印在**左臂袖子上**（观者右侧手臂），**胸口区域干净无图案**（因为有胸包遮挡）
- **内搭**：白 T 恤下摆露出约 2cm
- **胸包**：黑色小号斜跨胸包（fanny pack / chest sling），从右肩斜跨到左胸/腰侧，包带和包身边缘有荧光青包边，包正面有一个小荧光青龙头 logo
- **手表**：左手腕黑色方形智能手表
- **短裤**：炭黑色工装短裤，带两侧大口袋
- **袜子**：白色中筒袜
- **鞋**：白色球鞋，荧光青鞋带 + 荧光青鞋底 + 侧面荧光青小勾
- **手持物**：右手抱一台合上的银色薄笔记本电脑（自然贴在身体右侧）

## 十、两种插图范式

阿砚 IP 用于两种不同类型的插图，结构完全不同，按场景选择。

### 范式 A：日常封面模板（待 v2 定稿）

> 参考：macOS 文件图标，文档卡片 + 预览小窗 + 放大镜

- 比例：3:4 竖版
- 结构：白色圆角文档卡片，右上角折角，中央偏上一个小预览窗（30% 卡片大小），放大镜压在窗右下角，底部留 1/3 空白放标题
- 用途：每篇笔记/文章封面，批量复用，换预览窗里的小场景即可
- 样图：待生成 v2 定稿

### 范式 B：深度知识科普图（已用 Sass 炼金工坊验证）

> 样图：`样图-知识插图-阿砚Sass炼金工坊.png`

**结构（3:2 横版）：**
- 顶部：卷轴大标题 + 副标题横幅（点题）
- 中央：阿砚站在主题场景中央（炼金工坊/工厂/天文台等），手持道具（玻璃棒/扳手/望远镜），阿龙趴肩上
- 桌上/前景：主题相关的可视化元素（烧瓶+管道=变量/嵌套/混合/继承）
- 左侧："Before" 混乱状态（难过乌云脸 + 杂乱代码/旧纸张）
- 右侧："After" 整洁状态（开心白云脸 + 整洁代码/羊皮卷）
- 上方飘着一个发光云朵/气泡，里面是核心代码片段
- 底部：卷轴总结横幅「核心概念 = A + B + C + D」
- 角色旁一个小对话气泡「一句点题的话」

**主题隐喻表（可扩展）：**

| 主题 | 场景隐喻 | 道具 |
|------|---------|------|
| CSS/Sass | 炼金工坊 | 玻璃棒、烧瓶 |
| Python | 工厂/机械车间 | 扳手、齿轮 |
| 数学 | 天文台/星象室 | 望远镜、星图 |
| 网络 | 邮局/交通枢纽 | 信封、信号塔 |
| Git | 时间旅行者车站 | 时钟、列车 |

**用途**：重点知识点的头图/科普长图，每张深度定制，不批量复用。
