## 💡 核心概念

`int(x, base=10)` 里的 `base` 指的是**输入字符串 `x` 按什么进制解读**，**输出永远是十进制的 `int` 对象**——不是"把结果转成 `base` 进制"。

这是最容易理解反的地方。同一个字符串，按不同进制读进来，得到不同的十进制整数：

```python
int('17', 10)   # 17   按十进制读
int('17', 8)    # 15   按八进制读：1*8 + 7 = 15
int('17', 16)   # 23   按十六进制读：1*16 + 7 = 23
int('1010', 2)  # 10   按二进制读
```

想**反过来**把十进制整数转成其他进制字符串，要用 `bin()` / `oct()` / `hex()`：

```python
oct(15)         # '0o17'
hex(23)        # '0x17'
bin(10)         # '0b1010'
```

## 🔍 详细说明

### 1. 一张表分清两个方向

| 写法 | 方向 | 含义 | 结果 |
|------|------|------|------|
| `int('17', 8)` | 八进制字符串 → 十进制 int | 把 `'17'` 当八进制读 | `15` |
| `int('17', 10)` | 十进制字符串 → 十进制 int | 把 `'17'` 当十进制读 | `17` |
| `int('17', 16)` | 十六进制字符串 → 十进制 int | 把 `'17'` 当十六进制读 | `23` |
| `oct(15)` | 十进制 int → 八进制字符串 | 把 `15` 格式化成八进制字面量 | `'0o17'` |
| `hex(23)` | 十进制 int → 十六进制字符串 | 把 `23` 格式化成十六进制字面量 | `'0x17'` |

> 🔑 一句话记：**`base` 管的是"从哪种进制读进来"，不是"转成哪种进制"。输出统一是十进制 int。**

### 2. base 的取值范围

`base` 可以是 `0` 或 `2 ~ 36` 之间的整数：

```python
int('z', 36)    # 35   三十六进制：0-9 + a-z
int('10', 2)    # 2    二进制
```

- **默认 `base=10`**：直接写 `int('17')` 就是按十进制读。
- **`base=0`**：根据字符串前缀自动推断进制——带 `0b`/`0o`/`0x` 前缀才按对应进制读，无前缀则按十进制读。

```python
int('0o17', 0)    # 15   自动识别为八进制
int('0x17', 0)    # 23   自动识别为十六进制
int('0b1010', 0)  # 10   自动识别为二进制
int('17', 0)      # 17   无前缀，按十进制
```

### 3. base=8 时输入必须是合法八进制数字

八进制每一位只能是 `0-7`。只要输入字符串里出现 `8` 或 `9`，就无法被八进制规则解析：

```python
int('17', 8)    # ✅ 15
int('18', 8)    # ❌ ValueError
int('777', 8)   # ✅ 511
```

## ⚡ 反例 / 边界

### 经典报错：`invalid literal for int() with base 8: '8'`

本意是想得到整数 `8`，却写成了 `int('8', 8)`，等于在告诉 Python："请把字符串 `'8'` 当作八进制数解读"——但 `8` 根本不是合法的八进制数字：

```python
int('8', 8)     # ❌ ValueError: invalid literal for int() with base 8: '8'
int('08', 8)    # ❌ 同样报错
int('09', 0)    # ❌ base=0 时：'0'开头被推断为八进制，9 非法

int('8')        # ✅ 默认 base=10，结果就是 8
int('08')       # ✅ 按十进制读，结果是 8
```

> ⚠️ 常见踩坑场景：解析时间 `08:30`、IP 地址、日期字符串时，若误用了 `base=8` 或 `base=0` 自动推断，只要数字段含 8/9 就会炸。**想得到整数 8，就用 `int('8')`，别写 `base=8`。**

### 边界 1：float 字符串不能带 base

`base` 参数只在输入是字符串时才有意义；输入是浮点数时不能传 `base`：

```python
int('3.14')     # ❌ ValueError（字符串里有小数点）
int(3.14)       # ✅ 3，直接截断小数部分
int(3.14, 8)    # ❌ TypeError: int() can't convert non-string with explicit base
```

### 边界 2：字符串里的正负号是允许的

```python
int('-17', 8)   # -15
int('+17', 16)  # 23
```

### 边界 3：base 不是 10 时，前导零不会自动当八进制

```python
int('017')      # 17   默认按十进制，前导零只是普通字符
int('017', 8)   # 15   显式指定才按八进制
```
