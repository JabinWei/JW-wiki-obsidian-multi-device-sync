# Composition
Main visual: One single Python snake (deep navy) sits at center as a careful librarian/annotator, using a small label-maker or ink stamp to attach neat little type-label tags onto several floating code snippets around it. Each code snippet is a rounded paper card holding a line of pseudo-code (like "def add(a, b):" or "name ="), and the snake stamps labels reading `int`, `str`, `list[int]`, `Optional[...]` onto them. A small magnifying glass (representing mypy, the static checker) hovers over one labeled snippet, inspecting it. Metaphor: type annotations as writing a manual / sticking labels onto code so humans and tools can read what type everything is — purely descriptive, not enforced at runtime.
