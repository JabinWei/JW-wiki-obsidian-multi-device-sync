# Composition
Main visual: A hand-drawn 2×2 coordinate grid (a cross-axes map) centered on a warm cream paper background, like a page from a sketchbook.

Axes, drawn as slightly wobbly hand-sketched lines with arrows:
- Horizontal axis (bottom), labeled at each end: left "静态" (static), right "动态" (dynamic). A small arrow above the axis reads "检查时机" (when types are checked).
- Vertical axis (left), labeled at top "强类型" (strong), at bottom "弱类型" (weak). A small arrow beside the axis reads "是否隐式转换" (implicit conversion).
- The two axes cross at the center, forming four quadrants. The crossing point and axes drawn in deep navy.

Four quadrants, each holding one hand-drawn language mascot icon with a small hand-lettered label beneath it:
- TOP-LEFT quadrant (static + strong): a steaming coffee cup icon (Java / C# / Go / Rust). Label: "静态强".
- TOP-RIGHT quadrant (dynamic + strong): a friendly hand-drawn Python snake, GLOWING with a soft coral highlight / halo ring around it to mark it as the star. It wears a tiny pride pin or holds up a small pennant flag. Label: "动态强 · Python". This is the punchline — Python lives here, NOT in the weak corner.
- BOTTOM-LEFT quadrant (static + weak): a small cog/gear icon (C / C++). Label: "静态弱".
- BOTTOM-RIGHT quadrant (dynamic + weak): a small lightning-bolt icon (JavaScript / PHP). Label: "动态弱".

Metaphor: the cover is a "map" showing that static/dynamic and strong/weak are two INDEPENDENT axes you plot languages on — not one single "how good is the language" scale. The highlighted Python snake in the dynamic+strong quadrant visually corrects the common misconception.
