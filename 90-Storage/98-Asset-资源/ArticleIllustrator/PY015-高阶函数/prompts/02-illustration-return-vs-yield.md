Illustration: return vs yield — clear side-by-side comparison.

STYLE: Sketch-notes educational diagram. Warm cream paper, hand-drawn lines, soft pastels. Clean, one concept.

CONTENT: Two-column comparison on cream paper:

LEFT "return": 
- Function runs from start to end
- Returns ONE value and exits
- Function state is destroyed
- Call again = starts fresh
- Normal function

RIGHT "yield":
- Function pauses at each yield
- Can produce MULTIPLE values
- Function state is preserved
- Call next() = resumes from pause
- Generator function

CENTER ILLUSTRATIONS: 
- Return: single arrow → one result, then stop
- Yield: circular flow with pause markers: yield 1 → pause → yield 2 → pause → yield 3 → StopIteration

BOTTOM: "普通函数一次返回，生成器函数多次产出"
