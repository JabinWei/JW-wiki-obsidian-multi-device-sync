Illustration: Python variable model — label model vs box model.

STYLE: Sketch-notes educational comparison. Warm cream paper, hand-drawn lines, soft pastels.

CONTENT: Two-column comparison:

LEFT "传统语言 (C/Java): Box Model":
- A storage box labeled "a" containing the value "10" inside
- Variable IS the box — contains the data
- ❌ "a=10 表示把 10 放进 a 这个盒子"

RIGHT "Python: Label Model":  
- A sticky note/label "a" pointing to an independent object "10" floating nearby
- Variable IS the label — points to the object
- ✅ "a=10 表示贴个标签 a 在对象 10 上"
- Second label "b" also pointing to same "10" — b=a 之后两个标签指向同一个对象

BOTTOM NOTE: "Python 变量 = 标签（引用），不是容器（盒子）"
