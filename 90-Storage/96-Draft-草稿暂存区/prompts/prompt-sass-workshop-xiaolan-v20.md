# Sass Alchemy Workshop — starring 小蓝 (Xiaolan) IP — Gouache Style

A knowledge illustration explaining Sass (CSS preprocessor) in an alchemy workshop theme.

**Style**: gouache (opaque watercolor) illustration, clean solid color blocks, gentle matte brush strokes, NO heavy paper grain, matte warm tones, Ghibli-esque storybook feel. Richly detailed knowledge illustration, horizontal composition.

**Main character (小蓝 from IP spec)**:
- chibi boy ~2.5 head-tall, standing behind a wooden alchemy table
- short spiky crew cut (deep navy-indigo), NO glasses, calm cute smile
- deep navy hoodie with hood UP, a stylized cyan dragon graphic on chest
- his tiny teal dragon friend 阿龙 perched on his shoulder (small chibi teal dragon, cream belly)
- holding a thin glass stirring rod, stirring a glowing purple flask like a potion
- wearing a small leather tool belt / apron over hoodie (alchemist twist)

**Setting**:
- wooden alchemy workshop interior, shelves behind him lined with colorful glass potion bottles
- wooden scrolls hanging on walls, dried herbs, butterflies on windows
- purple wisteria flowers hanging from top corners
- warm magical glow from flasks

**Composition (horizontal 3:2)**:
- Top: a horizontal wooden scroll banner with big title "Sass 炼金工坊"
- Below title: a smaller ribbon banner "Sass = CSS 预处理器，用编程方式写样式 🧪"
- Center: 小蓝 behind alchemy table with 4 flasks connected by glass tubes:
  - Pink flask labeled "变量 $color"
  - Purple swirl flask labeled "嵌套 &"
  - Blue bubble flask labeled "混合 @mixin"
  - Green flask labeled "继承 @extend"
- A glowing purple cloud above the central flask contains small code:
  ```
  CSS {
    .container {
      &.box { @include flex-center; }
    }
  }
  ```
- Bottom: a wide wooden scroll banner: "Sass = 变量 + 嵌套 + 混合 + 继承"

**Left side (Before — messy CSS)**:
- A sad frowning cloud face icon
- Title "Before (messy CSS)"

  ```

  ...

**Right side (After — organized Sass)**:
- A happy smiling cloud face icon
- Title "After (organized Sass)"
- A wooden scroll with clean Sass code:
  ```
